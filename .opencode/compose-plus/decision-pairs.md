4. Капы не трогаем: класс 7 (хватает: 8Б 7+7+7+6+6, 9Б 7+7+7+7+6), учитель 6 (D-04 FROZEN).

## Решение (OWN SYNTHESIS)

- **Колонка Pair (10-я, опциональная)**: одинаковое значение в 2 строках одного класса = одновременные уроки (общий SyncGroupId + группы A/B). Пустая = как раньше (совместимость с 7/9-колоночными файлами).
- Правила валидации (fail-loud, русские тексты): ровно 2 строки; один класс; равные часы (resolved); разные учителя; не сплит-строка; scope PairId — в пределах класса.
- Импортер обеспечивает группы A/B класса (создаёт при отсутствии), member1→A, member2→B (порядок файла, детерминирован).
- Билдер/жадный/валидатор **без изменений** (проверено чтением — семантика уже есть).
- Дефолт сетки 5×7 → **5×8** (XAML DataView + сигнатура Import): только добавляет вместимость, ранее возможные решения остаются возможны (слоты 1–7 ⊆ 1–8), капы дней не меняются. D-pair-01.
- Данные: генератор build_load_5-11.py патчится (разбивка строк + Pair), файл регенерируется (408 строк, 769 ч — сумма та же).
