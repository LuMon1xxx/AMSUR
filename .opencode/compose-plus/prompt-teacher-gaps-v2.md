## 4. Задача: сделать ЛУЧШЕ человека (цель ≤140 окон, победа = строго меньше 140)

Ограничения (железно): pupilHard==0 (0 окон и 0 поздних стартов у учеников),
СанПиН-кэпы дня (5–6 кл ≤6, 7–11 ≤7), перегруз учителя ≤10/день, Hard=0,
веса менять только через RuleCatalog с bump версии (см. D-50, сейчас v6),
полный сьют зелёный, детерминизм по seed.

Что реализовать, по приоритету:

1. **Doubles-adjacency терм (главный рычаг).** Парные уроки (один предмет 2 раза в день
   у класса) ставить рядом, сдвоенно. Приоритет предметам: математика, физика,
   русский язык и литература, белорусский язык и литература (+ химия/биология/информатика
   как второй эшелон; физра/труды/искусство — без бонуса). Строгая верхняя граница
   по ФИНАЛу: только 32 дыры лежат между слотами разбросанных дублей → реально −15..−25.
   Реализация как ① ранее: каталог + SoftEvaluator + SearchIndex-паритет + Explainer-имя
   + тесты паритета (образец — `ActiveDayTests`, `TeacherDayLnsTests`).
2. **Цена открытого учителе-дня (не дёргать учителя в новый день).** Инфраструктура
   `teacher-active-day` (default 0) уже есть — как чистый вес не работает (закрыть день
   одиночными ходами нельзя, замер 0 эффекта). Поэтому только связкой:
   compact-Replant + TeacherDayLns (рушить рваный день целиком + contention + пересев
   компактно). Цель: 204 → ≤181 учителе-дня при тех же уроках.
3. **Отбор по дырам + multi-seed.** Оркестратор уже multi-seed — сменить критерий приёмки
   Top-5 с min-soft на min-gaps (решениe пользователя уже есть: делать). Best-of-3 seeds
   даёт −10..−20 бесплатно (было 328/290/300). Плюс полный TF+LNS-прогон до полного
   покрытия с перезаписью `АМСУР_движок_ФИНАЛ.xlsx` и перегенерацией `АМСУР_движок_по_дням/`.
4. Если 1–3 не дадут ≤140: **full-day ruin** (рушить целые дни топ-рваных учителей,
   не топ-16 дней), затем структурное (учителя через смены — отдельным решением).

Прогноз: 265 − ~20 (adjacency) − ~15 (seeds) ≈ **~220–230 (~1.6x)**. До ≤140 дотянуть
только связкой всего + full-day ruin. Честно фиксируй каждый замер таблицей
(конфиг | дыры | failedDays | pupilHard | soft), pupilHard=3 при частичном покрытии —
артефакт, помечать.

## 5. Протокол приёмки (без него «готово» запрещено)

1. Сеточная метрика in-scope без служебного по новым файлам + pupilHard==0.
2. Парное сравнение по общим учителям (было 28:5:9 в пользу школы — перевернуть).
3. СанПиН-аудит: перегруз дня, старты, окна учеников, дубли рядом %.
4. Полный сьют зелёный; `RealTeacherTests` 2/2; greedy-покрытие без регресса (было 864–868/890).
5. Победа = **≤140** (строго лучше человека). 141–230 = «прогресс, не победа».
