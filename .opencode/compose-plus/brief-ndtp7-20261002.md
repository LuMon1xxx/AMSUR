# Бриф НДТП-7 (02.10.2026): 7 требований школы + PDF к 05.10

## Что строим
До подачи на январскую смену НДТП (дедлайн 05.10.2026) внедрить в ядро АМСУР
7 требований, полученных от школы, и собрать PDF проекта (≤10 стр, А4, 14pt,
поля 2/2/3/1, нумерация внизу по центру) + DOCX. Характеристика из школы уже есть.

## Стек
C# / .NET 10, WPF (MVVM), SQLite (raw), OR-Tools CP-SAT + собственный поиск
(Greedy + CompactRepair + VND + LNS). Тесты: `dotnet test src/Amsur.Tests`.

## 7 требований (подтверждены пользователем 02.10)
1. Классный час и факультативы — в расписании есть, но уроком НЕ считаются
   (не входят в часы учеников и учителей, не создают окон).
2. Самые тяжёлые дни — Вт, Ср, Пт (пик нагрузки).
3. Физкультура не может стоять 3 дня подряд.
4. Физра, математика/алгебра/геометрия, русский, белорусский, иностранный,
   химия, физика — первым/последним уроком не более 1 раза в неделю.
5. Сложные и лёгкие уроки должны чередоваться в течение дня.
6. Норма учителя — 25 ч/нед (индикатор + контроль, без ломки покрытия).
7. ВОВ — обязательный факультатив 9-х классов в начале/конце дня,
   уроком не считается (как классный час).

## НЕ-цели (до подачи)
- Не ломать стабильный результат (134 окна движка vs 140 школы — победный).
- Не переписывать UI/экспорт; только точечные подписи (нагрузка учителя, бейджи).
- Не заявлять СанПиН-соблюдение как юрфакт (NEEDS-CHECK остаётся).

## Критерии приёмки
1. `dotnet build src/Amsur.slnx` — 0 ошибок.
2. Полный сьют зелёный (допущен только заранее известный карантин D-35).
3. Каждый из 7 пунктов покрыт хотя бы одним новым тестом.
4. PDF+DOCX в `Docs_Contest/`: ≤10 стр, 14pt, поля 30/10/20/20 мм, нумерация.
5. Демо-сценарий (DemoSchool) генерируется, классный час/ВОВ на краю дня,
   в часах не посчитаны.
