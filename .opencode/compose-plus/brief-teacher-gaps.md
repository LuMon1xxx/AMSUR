# BRIEF — обогнать человека по окнам учителей (23.09.2026)

Что строим: пакет улучшений движка, цель ≤140 окон учителей (строго лучше человека).
Стек: .NET 10, WPF, SQLite raw, OR-Tools CP-SAT + свой поиск (Greedy + CompactRepair + VND + LNS + TeacherDayLns).

Ключевые фичи (3–7):
1. Doubles-adjacency терм (главный рычаг, граница −15..−25).
2. Цена открытого учителе-дня только связкой compact-Replant + TeacherDayLns (204 → ≤181 дня).
3. Отбор Top-5 по дырам + multi-seed Best-of-3 (−10..−20 бесплатно).
4. Полный TF+LNS-прогон с перезаписью ФИНАЛа (по команде).
5. Запасной: full-day ruin, затем структура (учителя через смены).

НЕ-цели: смена дефолтов v6 без замера, трогать смены/bands, Phase B threshold 300, CP-SAT, персист пилота (StableKey сменились), коммиты без команды.

Критерии приёмки (проверяемые):
1. Сеточная метрика in-scope без служебного (клетки 1–12, цех/к-ч/над/аст/деж excluded), окно = пустой урок между первым и последним.
2. pupilHard==0 (0 окон + 0 поздних стартов учеников), СанПиН-кэпы (5–6 ≤6, 7–11 ≤7), учитель ≤10/день, Hard=0.
3. Парное сравнение по общим учителям (было 28:5 в пользу школы — перевернуть).
4. Сьют зелёный (~317 тестов), RealTeacherTests 2/2, greedy 864–868/890 без регресса.
5. Победа = строго <140. 141–230 = прогресс, не победа.
6. Каждый замер — таблицей (конфиг | дыры | failedDays | pupilHard | soft).
