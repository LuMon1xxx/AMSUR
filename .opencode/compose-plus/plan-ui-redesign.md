# AMSUR UI Redesign V3 — детальный план (вариант В, 20.09.2026)

> Статус: ПЛАН, код не тронут. Ждёт аппрува пользователя.
> Источник дизайна: `stitch_school_timetable_desktop/` (9 экранов, тёмный «пульт»)
> + локальные `_1.._9/code.html`. Stitch MCP подключён (list работает),
> generate/edit таймаутят — адаптация делается вручную по этому плану.
> Решение S5-предварительное: тёмный каркас Stitch → светлая тёплая тема,
> честные тексты, упрощение. Тёмная тема — пакетом позже по тем же токенам.

## 0. Принципы (не нарушать)

1. Один завуч 50+ лет, не технарь — главный судья каждого экрана.
2. Честность: никаких выдуманных цифр/гарантий/школ/людей (реестр §7).
3. Ручную правку НЕ трогаем (ни UI, ни логику): affordance правки прячем.
4. Шрифт только Segoe UI (системный). Минимум 13px обычный, 12px подписи.
5. Тёмная тема — вторым пакетом, структура XAML одна (словари токенов).

## 1. Архитектура: одно окно (вместо 7 окон)

Сейчас: MainWindow, GenerateWindow, ScheduleWindow, SettingsWindow,
SchoolDataWindow, ExportWindow, HelpWindow (+ QualityDetails, DangerDialog,
LoadRowWindow) — отдельные Window.

Станет: `ShellWindow` (хром + rail 240px + `ContentControl` регион) + Views:
`DashboardView`, `DataView`, `GenerateView`, `ScheduleView` (НОВАЯ сетка,
см. P2), `SettingsView`, `ExportView`, `HelpView` (UserControl'ы).
Навигация: `INavigator { CurrentView, NavigateTo(name), Back }` в AppSession
(без новых библиотек). Модальными остаются ТОЛЬКО системные диалоги
(открыть/сохранить файл). DangerConfirm → inline-панель подтверждения
внутри view. QualityDetails → раскрывающаяся панель внутри GenerateView.

Файлы: `src/Amsur.Wpf/Shell/` (ShellWindow, NavRail), `src/Amsur.Wpf/Views/`
(7 views + MascotControl), `src/Amsur.Wpf/Themes/` (Light.xaml сейчас,
Dark.xaml позже; ключи 1-в-1 как App.xaml B*/C*).

## 8. Риски

- Сетка 40 классов: лаги без виртуализации → рендер только выбранного
  класса + замер (митигация в P-D2).
- XAML-тесты завязаны на Window → миграция в P-D4 (не раньше, иначе шум).
- Stitch-шрифты не в WPF → Segoe UI, размеры +1..2pt от макета.
- Сова SVG→XAML: если криво — PNG-рендер 2 размера (fallback готов).
- Scope-creep («а давай ещё…») → всё новое только через этот план.
