# DECISION — doubles-adjacency + active-day связка + seeds (23.09.2026, v1)

Каноническое решение текущей итерации (история редизайна — в decision.md, не трогать).

## 1. Doubles-adjacency терм (принято, дизайн cp-logic)
- Код: `doubles-adjacency`. Каталог v6 → v7 (bump, политика D-50).
- Дефолт: 10 (порядок heavy-edge 20 / subject-maxperday 15, слабее student-gap 100). Диапазон 0..100.
  Профили STANDARD/STUDENT_FRIENDLY/TEACHER_FRIENDLY — одинаково (терм ученический).
  Сохранённые CUSTOM-профили старых версий при bump откатываются на STANDARD
  штатным механизмом проверки версии (как в D-50) — новый дефолт применяется единообразно.
- Единица: K=(classId, subjectId, dayIndex), только eligible (GroupId==null && SyncGroupId==null && InScope).
  `units(K) = 1 iff eligCount==2 && distinct==2 && |s1-s2|>1 else 0`.
  Штраф: `Σ units(K) * wDoubles * GradeW(classId)` (R8: вес параллели, учителя/кабинеты не взвешиваются).
- Чистая функция `SoftUnits.DoublesScattered` — единый источник (SoftEvaluator + Explainer.CountUnits; SearchIndex зеркалит + паритет-тест).
- Инварианты: INV-D1 eligibility, INV-D2 count==2 (тройки 0), INV-D3 DISTINCT==2, INV-D4 аддитивность с subject-maxperday (guards запрещены), INV-D5 паритет индекс/полный, INV-D6 room-only дельта 0, INV-D7 симметрия swap, INV-D8 только GradeW.
- Предметный приоритет (§4 промта: эшелон 1/2, физра/труды/искусство без бонуса): НЕ в формуле v1.
  Причина: строгая граница 32 дыры посчитана без приоритетов; вводить список предметов = произвол без заказчика + риск паритета.
  Отложено как настройка v2 (предикат IsInScope/вес по предмету) только если A/B покажет перекос в физру/труды.
- Explainer: HumanName «Разбросанные сдвоенные уроки», строки только по разбросанным (класс, предмет, день+1, слоты a/b).

## 2. Active-day связка (принято)

  Параметры LNS не менять без замера (topK=16, restarts=4). gapsFirst=только эксперименты (ухудшает soft +32%, failedDays=2).
