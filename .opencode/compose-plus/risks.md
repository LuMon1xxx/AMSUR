# RISKS — остаточные риски редизайна (только UI)

- **R1 Выдуманные цифры просочатся в UI.** Триггер: в XAML появляется число без binding к контракту (%, итерации, память). Митигация: ревью каждого пакета grep'ом чисел; правило «нет binding — нет цифры».
- **R2 Мёртвая кнопка (masking).** Триггер: кликабельный контрол без хендлера/контракта. Митигация: каждая кнопка в пакете маппится на таблицу plan.md; disabled только с бейджем «Скоро» (PDF).
- **R3 Регресс STA/E2E.** Триггер: переименование x:Name/x:FieldModifier, ломающее WpfShellTests/WorkingVersionFlowTests. Митигация: имена контролов не переименовывать, только стили/композицию; полный тест после каждого пакета.
- **R4 Потеря доступности Generate (F5/EXPERT).** Триггер: EXPERT не открывает Settings, CTA не запускает генерацию без данных. Митигация: сохранить хендлеры OnGenerate/OnModeChecked, CTA disabled без HasData.
- **R5 Кабинет-фильтр как scope-creep.** Триггер: фильтр требует изменения store/problem. Митигация: только _allRows.Where(r.RoomName==name); если Rooms пусты («—») — фильтр показывает пусто честно, без новых сущностей.
- **R6 Preview-вердикты в 3 стиля.** Триггер: парсинг VerdictText ломается на новых формулировках. Митигация: стилизация по префиксу мягкая (fallback — нейтральный стиль), текст не перефразируем.
- **R7 Скриншот-цикл без конца.** Триггер: пиксельная гонка со Stitch. Митигация: max 2–3 раунда vision на окно; дальше — backlog, окно считается готовым при отсутствии confirmed CRITICAL/HIGH.
