## Решения пользователя (зафиксированы дословно)

2. Готовность БД — только из реальных данных. % нет → показываем counts + ошибки, без фиктивных %.
3. Фильтр Кабинет — только если UI-фильтрация без смены контрактов. Проверка: ScheduleRowVm уже несёт RoomName/RoomId, _allRows в памяти → фильтр реализуем в ApplyViewFilter + FillNameBox. РЕШЕНИЕ: добавить.
4. ExportWindow — отдельным окном, только Excel, PDF disabled «Скоро», без журнала/полноэкранного.
5. Dead controls — замены из аудита сохраняются (см. §5).
6. S5 = реализуемый дизайн.

## Вердикты по спорным метрикам
- **Индекс строгости 98.4% (Stitch amsur_5): ОТКЛОНЕНО.** Почему: EffectiveRuleSet.Weights разнородны (100/100/20/10/2/5/15...), глобального % в коде нет, HumanScale даёт только per-code лейблы. Любой % = выдумка. Замена: строка `Профиль · Каталог v3` + per-slider `HumanScale.Label + вес числом мелко` (уже есть в backend).
- **Готовность БД 96.8% + прогресс-бар: ОТКЛОНЕНО.** Почему: Import fail-loud (либо принято целиком, либо нет), метрики нет. Замена: `N классов · M учителей · K уроков · Дни×Слоты` из AppSession.Summary + `Ошибок: N / Готово (0 ошибок)` из LastImportErrors + время импорта сессии (UI-only timestamp, честно подписан).
- **Пул 3/5, итерации #14820, 820/сек, sol-... IDs, 14.8тыс перестановок, память 342МБ, потоки 8x, Branch&Cut+LNS, масштаб 85% A1:F48: ОТКЛОНЕНО как живые цифры.** Почему: orchestrator/VM такого не отдают; выдумывать запрещено. Замена: показывать только то, что отдаёт GenerateViewModel (Title/Status/Stages/FirstFeasible/Best/Candidates/Elapsed/Top5/Trajectory/Diagnostics-подробнее). Diagnostics оставить под Expander «Подробнее» как сейчас.
- **Учителя 89 vs 100, кабинеты 24, 1200ч:** показывать только из Summary активного входа, не копировать цифры со скриншотов.
- **Времена режимов ~20с/~2м/~8м:** GenerateModes хранит BudgetSeconds 3/12/30/12 + Seeds. Показ `~N сек/мин` как производная от BudgetSeconds — честно (подпись «лимит»). Сложность 3.4/5 — выдумка, не показываем.

## Что отклонено из Stitch (с причиной)
- Профили▾ в сайдбаре → нет окна; пресеты уже в Настройках. Убрать пункт везде.
- DnD карточек → нет AllowDrop/backend; оставить панель Переместить+Проверить/Сохранить.
- Undo/Redo, автопочинка → нет ChangeSet-журнала (D-21). Не рисовать.
- CRUD нагрузки (Добавить строку/Изменить/пагинация как живая/Проигнорировать) → нет CRUD/partial-import. Только чтение + Скачать/Загрузить/Выбрать другой файл.
- Teacher/Cabinet листы экспорта, титульный лист, журнал, fullscreen, табы Свод_Учителя/Кабинеты → exporter пишет один лист «Расписание» по классам. Не рисовать как рабочие.
- PDF рабочий → Excel only. PDF карточка disabled «Скоро».
- Тёмная тема, мобилка, колокол живой, sync живой → не делать.
- Side-by-side сравнение → нет diff UI; оставить Compare-строки в карточках (DifferenceLines уже есть).
