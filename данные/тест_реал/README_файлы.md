## Как сравнивать честно
Окна учителей: ЧЕЛОВЕК_Учителя_*.xlsx vs АМСУР_движок_по_дням/АМСУР_Учителя_*.xlsx, только клетки 1–12,
служебное (цех/к/ч/над/аст/деж) НЕ считается, окно = пустой урок между первым и последним
уроком учителя в день. Чистый итог 23.09: **140 vs 315** (14.8 vs 35.5 на 100 уроков).
Итог 24.09: **человек 140 vs движок-v4 132** (14.8 vs 14.9 на 100; парное 14:19:10).
Правильные фамилии: Городионок, Плужникова. Денискин — 14 ч в нагрузке. Бесфамильно — исключена.
