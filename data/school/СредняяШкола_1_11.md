# Средняя школа 2026/2027 — набор для финального теста

Файл: `СредняяШкола_1_11.xlsx`

## Что это

Полная белорусская школа 1–11 классов, собранная под действующие нормы.
Все фамилии вымышлены, кабинеты с этажной нумерацией. Данные не взяты
из реальной школы — это модельный набор для демонстрации.

## Как проверить

1. «Данные» → «Загрузить Excel» → `СредняяШкола_1_11.xlsx`.
2. «Создание расписания» → «Стандарт» → «Сгенерировать».
3. Ожидаемо: 657 из 657 уроков, 0 жёстких нарушений, около 20–40 секунд,
   пять вариантов в пуле.

## Известные ограничения

- СанПиН запрещает физкультуру и в два дня подряд; программа проверяет
  только три подряд. На этом наборе две пары подряд возможны.
- Повтор физкультуры в один день ограничен мягким штрафом, а не запретом.
  В редких случаях возможны два урока физкультуры в день у старших классов.
- Вместимость кабинетов по числу мест не проверяется.
