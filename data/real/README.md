- `РеальнаяНагрузка_5-11.xlsx` — сверенная нагрузка
  (`RealTeacherTests`, `ScratchGen.BuildAll`).
- `РеальнаяНагрузка_5-11_backup_20260922.xlsx` — страховка входа.
- `учителя_персональные.xlsx` — персональные данные учителей.

  `teachers_grid.py` / `classes_grid.py` — сетки,

(разовые прогоны `ScratchGen` / `FullRunV2`, сейчас под Skip).
