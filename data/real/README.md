# real — реальный пилот СШ №8 (5–11)

Данные реальной школы (СШ №8 г. Жодино), оцифрованные с фото висящего
расписания. Часть файлов читают тесты — **не переименовывать и не двигать**.

## Вход (читают тесты)
- `РеальнаяНагрузка_5-11.xlsx` — сверенная нагрузка
  (`RealTeacherTests`, `ScratchGen.BuildAll`).
- `УЧИТЕЛЯ_ПРЕДМЕТЫ_КЛАССЫ.xlsx` — производный ростер (учителя × предметы/классы).
- `РеальнаяНагрузка_5-11_v5-12.xlsx` — вариант нагрузки (v5–12).

## Человек (школа, фото-верифицировано) — `ЧЕЛОВЕК_школа_с_фото/`
- `ЧЕЛОВЕК_Учителя_<день>.xlsx` (Пн..Пт) — висящее расписание учителей, фото 20.09.2026.
- `ЧЕЛОВЕК_Ученики_5-11_расписание.xlsx` — расписание по классам/дням (фото).
- `ЧЕЛОВЕК_Ученики_5-11_1в1_со_стенда.xlsx` — сверка 1-в-1 со стендом.

## Расшифровка и анализ
- `учителя_расшифровка.md` — расшифровка фамилий/предметов.
- `АНАЛИЗ_ЧЕЛОВЕК_VS_АЛГОРИТМ.md` — сравнение расписания человека и движка по клеткам.

## Генераторы/сверки (`*.py`)
- `make_real_load.py` — строит вход из фото/ростера.
- `teachers_grid.py`, `classes_grid.py` — сетки.
- `crosscheck.py`, `crosscheck2.py`, `pure.py`, `anchor.py`, `v2_audit.py` — сверки.

## Как сравнивать честно (методика)
Окна учителей: `ЧЕЛОВЕК_Учителя_*.xlsx` против вывода движка, только клетки
1–12; служебное (цех/к/ч/над/аст/деж) НЕ считается; окно = пустой урок между
первым и последним уроком учителя в день. Чистый итог 23.09: 140 vs 315
(14.8 vs 35.5 на 100 уроков). Итог 24.09: **человек 140 vs движок 132**
(14.8 vs 14.9 на 100). Правильные фамилии: Городионок, Плужникова.
Денискин — 14 ч в нагрузке. «Бесфамильно» — исключена.
