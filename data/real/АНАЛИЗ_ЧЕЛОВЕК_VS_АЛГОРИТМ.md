## 5. Почему движок проигрывает: 5 причин с доказательствами

**П1. Дыры «несущие» — одиночными ходами не чинятся (доказано экспериментом).**
Прототип чинки «крайнее занятие → внутренняя дыра» с FullValidator-gate:
1116 проверок → принята 1 (−2 дыры, а softTotal даже вырос 2735→2739).
Причины отказов: room-overflow 939, group-collision 728, shift-domain 377.
Перевод: в дыру учителя нельзя встать, потому что там занят кабинет, или класс
занят другим учителем, или самому занятию туда нельзя по смене. Пустоты нет —
есть конфликт интересов, который single/swap-окрестность не распутывает.

**П2. Веса не решают (доказано экспериментом).**
Прогон VND30 с профилем TEACHER_FRIENDLY (окна 20/5 вместо 10/2):
351→341 дыра (−3%). Поиск не недостимулирован — он в структурном локальном оптимуме.
Кстати, иерархия весов буквально дешевле ценит дыры учителей (10), чем огрехи
предметов (heavy-edge 20): движок по дизайну разбрасывает учителей ради предметов.

**П3. Размазанность: 204 учителе-дня против 176.**
Движок мажет нагрузку тоньше → рвётся чаще. В целевой функции нет цены
«открытого учителе-дня» (bin-packing-давления): день открыть бесплатно, дыры потом.

**П4. Дыры везде, пик — средние дни.**
Дыры по слотам 2–10 без единственной границы (пики 5/7/8, но везде).
Средняя рваность по нагрузке дня: пик при 5 уроках (2,28), дни на 6–7 уроков
упакованы (1,3) — движок пакует большие дни и рассыпает средние. У школы 0,7–1,2
при любой нагрузке: человек компактит каждый день отдельно.

**П5. Межсменка — половина беды, но не вся.**
Из 315 окон движка 250 — в днях через обе смены (у школы 118 при тех же ~95 днях).
Cross-вес 2 это легализует. Но даже без межсменки счёт был бы ~65 vs ~25 — всё равно вдвое.

## 8. Чем пожертвовал человек? Ответ: ничем — он просто лучше пакует (23.09)

Проверены все твёрдые нормы по клеткам (СанПиН-кэпы 5–6 кл ≤6, 7–11 ≤7 в день):

| Норма | Школа | Движок (ФИНАЛ) |
|---|---|---|
| Перегруз дня класса (сверх кэпа) | 1 случай (6 кл, 7 ур.) | 4 случая |
| Поздние старты учеников | 0 | 0 |
| Окна учеников | 0 | 0 |
| Перегруз учителя (>10/день; макс) | 0 (макс 10) | 0 (макс 10) |
| **Сдвоенные (повторы предмета в дне)** | **27, из них 89% рядом (сдвоенные)** | **95, из них рядом только 28%** |

**Главный ответ:** человек НЕ жертвует нормами — он держит их так же (а кэпы даже
лучше: 1 vs 4). Разница в мастерстве упаковки:
1. Человек раскладывает предмет ровно по неделе (27 дублей vs 95) и дубли ставит
   **сдвоенно** (89% рядом — лабораторные/пары без дыр). Движок дублит в 3,5 раза чаще
   и разбрасывает (только 28% рядом) — каждый разбросанный дубль = потенциальная дыра
   учителя. MaxPerDay=2 по умолчанию дубли из 2 уроков вообще не штрафует.
2. Человек компактит каждый учителе-день отдельно (0,76 дыры/день); движок торгует
   дыры (вес 10) за предметные совершенства (heavy 20, subj 15).
3. Отсюда следующий рычаг (не реализован): бонус сдвоенным / штраф разбросанным
   дублям (adjacency-терм). УТОЧНЕНИЕ 23.09 (строгий подсчёт по листу «Учителя»,
   888 строк, дыры сошлись 315 в 315): из 315 дыр только 32 лежат строго между
   слотами разбросанных дублей (68 дублей, 24 учителе-дня) — это ВЕРХНЯЯ граница
   терма; реально −15..−25 (конфликты). Остальные 283 дыры (90%) — общий разброс
   одиночных уроков, а не дубли. Прогноз combined: ~271 (LNS) − ~20 ≈ **240–250**,
   т.е. ~1,5x от школы (160), не «в разы». Для ≤160 нужны ещё: multi-seed отбор,
   full-day ruin и/или структурные изменения нагрузки (меньше учителей через смены).

## 14. Deep-dive 23.09: реальная причина разрыва (метод ловушек исключён)

**Главная формула (проверено двумя реализациями, 262=262):**
v2 = 262 дыры = **152 в 39 хвостах (дни с ≥3 дырами, 3.9/день) + 110 в 170
обычных днях (0.65/день)**. Обычные дни УЖЕ плотнее человека в среднем
(0.65 < 0.77 = 140/181). Вся болезнь — хвосты. У человека тоже есть хвосты
(15 дней / 49 дыр, 3.3/день), но их в 2.6 раза меньше.
Отсюда арифметика победы: хвосты 152 → ≤30 при сохранении обычных 110±20.

**Цепочка причин (каждая доказана цифрой):**
1. **Конструкция размазывает.** GreedyPlacer раскладывает каждый класс
   равномерно по дням (classDay least-loaded, D-28 — ради кэпов классов),
   слоты — с первого свободного. Учителя наследуют разброс: 5-дневок у v2
   **38 против 17 у человека** (3-дневок 1 vs 8; 4-дневок 3 vs 17);
   учителе-дней с ≤2 уроками **55 vs 23**; лишних дней по общим фамилиям +34.
   Клиника: Павлович 10 уроков за 2 дня у человека → 5 дней (4 тощих) у нас;
   Бурко/Денискин/Лащ/Коротченя 3→5 дней; Шаболтиев 1→3 дня на 4 урока.
2. **Поиск не умеет закрывать дни.** TeacherDayLns чинит учителе-день
   ВНУТРИ него (CompactHint тянет уроки обратно в рушимый день) и никогда не
   пробует выселить день целиком; contention ограничен 160 и днём; вес
   active-day как число доказанно не работает (0 эффекта — день одиночными
   ходами не закрыть). Счёт дней 209 — аттрактор всей архитектуры, а не шум.
3. **Хвосты не разбираются дневным ruin'ом.** Оракул gapsFirst (давление
   только на дыры, 180с, topK 24, restart 6, старт v2): 262→228, принято
   20/282, activeDays 207. Пол day-ruin окрестности ≈ 220–230. Остаток —
   только недельными совместными ходами (full-day ruin) или структурой.
4. **Сплит-синк teachers — отдельная яма.** 15 pair-bound учителей:
   v2 122 дыры (41.2/100) vs человек 52 (15.8/100) — человек сплиты держит
   БЕЗ штрафа, движок сыпет вдвое против своего же среднего (rest 23.6/100).
   Половину двигать по времени запрещено (sync), вместе их никто не двигает.
