# AMSUR (АМСУР) — Спецификация дизайн-системы и Handoff для WPF (.NET 10 / MVVM)

## 1. Введение и Архитектурные принципы
**АМСУР** — Автоматический модуль составления учебных расписаний. Профессиональное настольное Windows 11 приложение для завуча по учебной работе.
- **Главный девиз:** Maximum Power Inside. Minimum Complexity Outside.
- **Целевая платформа:** Windows 11 Desktop (WPF, .NET 10, C#, CommunityToolkit.Mvvm).
- **Разрешения экрана:** Базовое 1600×900 (16:9), отзывчивое масштабирование для 1280×720 и 1920×1080.
- **Композиция:** Вдохновлена `primer.png` (левая компактная навигация 240px, центральная рабочая зона, правая панель контекста/режима/качества 340px, верхний Windows Titlebar с окном пользователя и управлением окном).

## 5. Компоненты UI (WPF Control Styles)

1. **Titlebar (Заголовок Windows 11):**
   - Название программы "АМСУР — Автоматический модуль составления учебных расписаний", версия, статус сохранения, кнопка профиля (Иванова Е.В., Завуч), стандартные кнопки Windows (Свернуть, Развернуть, Закрыть).
2. **Left Navigation Rail / Sidebar:**
   - Элементы меню: Главная, Школа и данные, Расписание, Настройки качества, Экспорт и печать, Справка.
   - Активный пункт: фон `#EEF2FF`, текст и иконка `#4F46E5`, вертикальный индикатор слева 3px `#4F46E5`.
   - Внизу: виджет "Нужна помощь?" с быстрой ссылкой на контекстную документацию.
3. **Card Hero / Primary Action (Создать расписание):**
   - Акцентный градиент или сплошная плашка `#4F46E5` с мягким свечением.
   - Крупная белая кнопка с шевроном/иконкой запуска генерации.
4. **Generation Mode Cards (Выбор режима генерации):**
   - Карточки с радио-индикатором: Быстро, Стандарт (Рекомендуемый с бейджем), Максимальное качество, Экспертная настройка.
   - При выборе: синяя окантовка 1.5px `#4F46E5`, мягкий фон `#F5F7FF`.
5. **Quality Gauge / Аналитика качества:**
   - Четкие индикаторы: "Отличное расписание (96/100)", прогресс-бар, счетчики: "Окна учителей", "Окна классов (0)", "Межсменные перерывы", "Перегрузки кабинетов".
6. **Schedule Grid (Интерактивная сетка расписания):**
   - Режимы отображения: По классам (5А, 5Б...), По учителям, По кабинетам.
   - Дни недели (Пн-Сб), уроки 1-8.
   - Ячейка урока: Название предмета, Учитель, Кабинет, бейдж подгруппы.
   - Индикация конфликта: пунктирная или розовая рамка с иконкой ⚠ и всплывающим "Почему так?".
7. **Панель "Почему так?" (Explainability Panel):**
   - Всплывающий Drawer или диалог с понятным человеческим объяснением факторов выбора места урока CP-SAT алгоритмом без математического жаргона.
