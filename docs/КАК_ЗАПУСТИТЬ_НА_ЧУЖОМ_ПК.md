# АМСУР — как запустить на чужом ПК (показ научруку)

> Проверено дома 15.09.2026: `AMSUR.exe` запускается, висит без краша, убит штатно.
> Это самодостаточный single-file exe (~218 МБ, рантайм уже внутри) — **ничего устанавливать не нужно**.

## 1. Что лежит на флешке (E:\AMSUR)

```
E:\AMSUR\
  demo\
    AMSUR.exe                        ← двойной клик сюда
    DemoSchool.xlsx                  ← маленькая школа для быстрого демо
    RealSchool_Schedule.xlsx         ← типовая школа 40 классов
    RealSchool_Schedule_EPICJ.xlsx   ← эталонный результат (пример «как получается»)
    КАК_ЗАПУСТИТЬ.md                 ← этот файл
  src\                               ← чистые исходники (без bin/obj, ~1 МБ), показать код если спросят
  docs\                              ← *.md + primer.png из проекта
```

## 2. Требования к чужому ПК

- **Windows 10 / 11, 64-bit** (на macOS / Linux WPF не запустится — это нормально, так и сказать).
- ~300 МБ свободного места (если копируешь с флешки; можно запускать прямо с флешки, но медленнее).
- Права админа **не нужны**. Интернет **не нужен**.
- .NET устанавливать **не нужно** (exe self-contained, .NET 10 уже внутри).

## 3. Запуск (1 минута)

1. Воткни флешку → открой `E:\AMSUR\demo\`.
2. Двойной клик по **`AMSUR.exe`**.
3. Первый запуск может думать 5–10 сек — это распаковка, жди.
4. Если Windows SmartScreen ругнётся «Система Windows защитила ваш компьютер»:
   `Подробнее → Выполнить в любом случае`. Это штатно для exe без цифровой подписи.
5. Если антивирус спросит — `Разрешить` (файл твой, собран дома).
6. Откроется главное окно-dashboard: карточки школы/профиля, кнопка **«Сгенерировать расписание»**.

## 4. Сценарий показа (5 минут, выучи порядок)

| Время | Что делаешь | Что говоришь |
|---|---|---|
| 0:00 | Открыто главное окно | «АМСУР — автоввод нагрузки → генерация → Top-5 вариантов → правка → Excel. Стек: .NET 10, WPF, OR-Tools» |
| 0:30 | Покажи `DemoSchool.xlsx` (маленькая школа) | «Завуч заполняет такой шаблон, загружает — ошибки подсвечиваются списком что исправить» |
| 1:30 | Режим **Быстро (3 с)**, кнопка «Сгенерировать» | «Движок: greedy-старт → repair → локальный поиск. Детерминизм: тот же seed = тот же результат» |
| 2:30 | Покажи Top-5 + «Почему такая оценка» | «Не голая цифра, а человеческим языком: Отличное/Хорошее + топ-3 что улучшить. 188/188 тестов» |
| 3:30 | Открой `RealSchool_Schedule_EPICJ.xlsx` | «А это большая школа: 40 классов, 100 учителей — 0 окон у детей, проверено аудитом» |
| 4:30 | Ручная правка + выгрузка в Excel | «Запрещённую правку объяснит с причиной, разрешённую — выгрузит в Excel» |

Запасная фраза на каверзные вопросы: «СанПиН-веса пока не сверены с НПА — честно пишу это в ограничениях, нормативку не заявляю».

## 5. Если не запустилось (план Б)

1. **SmartScreen / антивирус** — см. п.3, это причина №1, лечится одной кнопкой.
2. **Запуск с флешки тормозит или виснет** — скопируй папку `demo` на `C:\Temp\AMSUR` и запускай оттуда.
3. **«Не хватает DLL / .NET»** — в этой сборке такого быть не должно (self-contained). Если вдруг:
   скачай с официального сайта Microsoft **.NET 10 Desktop Runtime (x64)**:
   `https://dotnet.microsoft.com/download/dotnet/10.0` → поставь → запусти снова.
4. **Старый Windows (7/8, 32-bit)** — не поддерживается, честно скажи: «нужен Win10/11 x64».
5. **Совсем ничего не помогло** — покажи исходники из `E:\AMSUR\src\` + скриншоты/доки из `docs\`,
   а демо договорись повторить на своём ноутбуке.

## 6. Что проверить ДО выхода из дома (чек-лист)

- [ ] Флешка вставлена, `E:\AMSUR\demo\AMSUR.exe` на месте (~218 МБ).
- [ ] Дома двойным кликом открылось главное окно (уже проверено 15.09.2026).
- [ ] Помнишь порядок сценария из п.4.
- [ ] Телефон с интернетом под рукой (раздать Wi-Fi если понадобится скачать рантайм — почти наверняка не понадобится).
- [ ] Опционально: залей копию `demo` в облако (Яндекс/Гугл диск) — если забудешь флешку.

## 7. Коротко для себя

Ничего скачивать заранее **не надо**. Exe самодостаточный, тесты 188/188 дома зелёные.
Единственный реальный риск — SmartScreen на чужом ПК, обходится за 10 секунд.
Удачи на показе!
