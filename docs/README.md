# Документация АМСУР

Вся проектная документация — здесь. Корень репо держим чистым:
`README.md`, `LICENSE`, `src/`, `docs/`, `data/`, `samples/`, `contest/`, `assets/`.

## Карта документов

| Файл | Что внутри |
|---|---|
| `PROJECT_STATUS.md` | Статус, тесты, настройка — единый файл состояния, читать первым |
| `КАК_ПОЛЬЗОВАТЬСЯ.md` | Руководство: быстрый старт (5 шагов), как работает, настройки, ограничения, FAQ |
| `КАК_ЗАПУСТИТЬ_НА_ЧУЖОМ_ПК.md` | Запуск вне dev-машины + сценарий показа научруку/комиссии |
| `DECISIONS.md` | Журнал архитектурных решений (D-01…) |
| `ПРОМО_БРИФ.md` | Брифинг для проморолика: факты о продукте, экраны, проверенные цифры, сценарии, чего говорить нельзя |
| `SANPIN_RB.md` | СанПиН-нормы РБ — рабочая выборка, **NEEDS-CHECK** (требует сверки с НПА) |
| `SUBJECTS_RB.md` | Предметы и часы РБ — рабочая выборка, **NEEDS-CHECK** |

## Архив процесса (`archive/`)

Исторические документы планирования/процесса — не для чтения «на ходу»,
нужны как след работы и доказательства (в т.ч. для защиты проекта):

| Файл | Что внутри |
|---|---|
| `archive/MASTER_PLAN.md` | Исходный план работ (P0–P4, EPIC A–K, ворота, DoD) |
| `archive/AMSUR_PLAN_FOR_AI_AGENT.md` | Исходная техническая спецификация (старт проекта) |
| `archive/AMSUR_PLAN_FOR_USER.md` | Исходный продуктовый план (старт проекта) |
| `archive/WORK_LOG.md` | Журнал работ (хронология, доказательства) |
| `archive/BENCHMARKS.md` | Замеры производительности (история) |

Связанные места: `../contest/` — материалы к конкурсам;
`../data/real/` — реальный пилот СШ №8 (нагрузка, скрипты, расшифровка);
`.opencode/compose-plus/` — брифы/решения/планы итераций (история Compose+).
